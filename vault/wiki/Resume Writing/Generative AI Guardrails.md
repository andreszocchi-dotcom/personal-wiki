# Generative AI Guardrails

Haas guidance on using GenAI for resumes: LLM output converges to average, so it should generate options and flag gaps while real experience and judgment decide.

### From Berkeley Haas Resume Standards
- A first draft feeling brilliant usually means inexperience with the task, not a great output. ([[raw/Berkeley Haas Resume Standards.md#12. Generative AI use — principles and guardrails|Berkeley Haas Resume Standards › 12. Generative AI use — principles and guardrails]])
- LLMs converge to average or below-average output by construction, and average is not the goal. ([[raw/Berkeley Haas Resume Standards.md#12. Generative AI use — principles and guardrails|Berkeley Haas Resume Standards › 12. Generative AI use — principles and guardrails]])
- Sanctioned uses: generate choices for a bullet, act as an editor flagging WHAT/HOW/IMPACT/WHY gaps, improve readability, analyze job descriptions. ([[raw/Berkeley Haas Resume Standards.md#12.
