# Bullet Emphasis Order

The same accomplishment can be resequenced to put first whatever the target audience cares about most. Resequencing, not word-swapping, is the tailoring tool.

## Details

<!-- source:berkeley-haas-resume-standards start -->
### From Berkeley Haas Resume Standards
- What+How+Why+Impact emphasizes the deliverable and process; Impact+How+What+Why leads with the number for metric-first readers. ([[raw/Berkeley Haas Resume Standards.md#2. Emphasis order is a deliberate lever, not fixed|Berkeley Haas Resume Standards › 2. Emphasis order is a deliberate lever, not fixed]])
- How+Impact+What+Why emphasizes methodology for analytical or technical roles; Why+What+How+Impact emphasizes strategic context, useful for pivot stories. ([[raw/Berkeley Haas Resume Standards.md#2. Emphasis order is a deliberate lever, not fixed|Berkeley Haas Resume Standards › 2. Emphasis order is a deliberate lever, not fixed]])
