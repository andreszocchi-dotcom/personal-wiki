# Resume Formatting Structure Choices

The choice between chronological and functional resume formats depends on the career narrative. Chronological is default, while functional groups skills across roles for big pivots.

## Details

<!-- source:berkeley-haas-resume-standards start -->
### From Berkeley Haas Resume Standards.md
- The Classic, default choice is the Chronological format. ([[raw/Berkeley Haas Resume Standards.md#Chronological format|Berkeley Haas Resume Standards.md › Chronological format]])
- Chronological format is good for single or adjacent pivots (e.g., PM→PMM). ([[raw/Berkeley Haas Resume Standards.md#Chronological format|Berkeley Haas Resume Standards.md › Chronological format]])
- The Functional format groups bullets by skill category across multiple employers. ([[raw/Berkeley Haas Resume Standards.md#Functional format|Berkeley Haas Resume Standards.md › Functional format]])
- Functional format is best for big pivots or unfamiliar target industries. ([[raw/Berkeley Haas Resume Standards.md#Functional format|Berkeley Haas Resume Standards.md › Functional format]])
- Company one-line descriptors should be italicized and provide unstated context. ([[raw/Berkeley Haas Resume Standards.md#Company one-line descriptors|Berkeley Haas Resume Standards.md › Company one-line descriptors]])
- The format for translating titles is: "official title" (US-equivalent role). ([[raw/Berkeley Haas Resume Standards.md#Title vs. (Role) translation|Berkeley Haas Resume Standards.md › Title vs. (Role) translation]])
- Never inflate claims beyond what is defensible, as reference checks verify titles and dates. ([[raw/Berkeley Haas Resume Standards.md#Cautionary tales (avoid)|Berkeley Haas Resume Standards.md › Cautionary tales (avoid)]])
