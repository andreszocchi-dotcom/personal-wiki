# Resume Emphasis Order Levers

The order of information in a bullet point can be deliberately resequenced to highlight what the target audience values most. This resequencing is a key tool for tailoring a resume.

### From Berkeley Haas Resume Standards.md
- What+How+Why+Impact emphasizes the deliverable and process. ([[raw/Berkeley Haas Resume Standards.md#2. Emphasis order is a deliberate lever, not fixed|Berkeley Haas Resume Standards.md › 2. Emphasis order is a deliberate lever, not fixed]])
- Impact+How+What+Why leads with the number, which is useful for audiences scanning for metrics first. ([[raw/Berkeley Haas Resume Standards.md#2. Emphasis order is a deliberate lever, not fixed|Berkeley Haas Resume Standards.md › 2. Emphasis order is a deliberate lever, not fixed]])
- How+Impact+What+Why emphasizes methodology or rigor, which is good for analytical/technical roles. ([[raw/Berkeley Haas Resume Standards.md#2. Emphasis order is a deliberate lever, not fixed|Berkeley Haas Resume Standards.md › 2. Emphasis order is a deliberate lever, not fixed]])
- Why+What+How+Impact emphasizes strategic context and motivation, useful when the 'why' is the differentiator. ([[raw/Berkeley Haas Resume Standards.md#2. Emphasis order is a deliberate lever, not fixed|Berkeley Haas Resume Standards.md › 2. Emphasis order is a deliberate lever, not fixed]])
